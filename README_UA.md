# DREAM19 — алгоритм формування портфеля проєктів відновлення мостів на основі великих даних

**Версія 1.0.0 · 25 листопада 2026 року**

Науковий репозиторій містить матеріали обчислювальної апробації розділу 3 дисертації з економіки. Зафіксовано програмний код, дані, результати національного експерименту на 19 мостах і допоміжні експерименти з НСЗУ та VIIRS. Досліджено сім бюджетних рівнів і 24 конфігурації дорожньої мережі. Результати відображають умовні модельні вигоди, а не фактичну національну інтенсивність руху чи рекомендації щодо фінансування конкретних проєктів.

## Відтворення розрахунків

У каталозі репозиторію виконати:

```sh
python3 -m pip install -r requirements.txt
bash run.sh
```

Після встановлення залежностей розрахунок працює без мережевих запитів, OSRM і доступу до приватного репозиторію. Скрипт перевіряє контрольні суми, відтворює ваги міжзональної гравітації, діагностичне масштабування попиту, відбір портфелів, сценарні економічні оцінки, експерименти НСЗУ та VIIRS у відкритій частині й архівує результати. Склад даних і значення показників пояснено в `DATA_DICTIONARY.md`; результати перевірки — у `RELEASE_VERIFICATION.md`. Відтворення за замороженими даними та маршрутними кешами не є повною побудовою дорожніх графів із первинних геоданих.

## Доступність даних

Репозиторій містить дослідницькі набори, сформовані на основі загальнодоступних джерел, та модельні дані, необхідні для відкритих розрахунків. Посилання на першоджерела, версії, атрибуція та умови повторного використання наведено в `SOURCES_AND_LICENSES.csv`. Для сторонніх даних діють умови відповідних джерел.

**TomTom.** Первинні та похідні числові дані TomTom і результати їх зіставлення не включено до публічного репозиторію. Відтворення відповідної перевірки другого контуру, зокрема зовнішнього зіставлення в експерименті VIIRS, потребує історичних даних та модуля розрахунку, які зберігаються у приватному дослідницькому репозиторії. Матеріали надаються автором на обґрунтовану вимогу в межах ліцензійних умов постачальника. Якщо передавання заборонене, доступ оформлюється згідно з умовами постачальника. Основні транспортні та економічні розрахунки, НСЗУ, контроль якості й відбір портфелів VIIRS відтворюються без TomTom.
